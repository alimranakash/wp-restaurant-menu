Custom Elementor widgets for restaurant websites.

== Description ==

WP Restaurant Menu adds a premium Restaurant Menu Elementor widget with image, title, dotted separator, price, description, external order link, and per-item sold out state.

== Installation ==

1. Upload the `wp-restaurant-menu` folder to `/wp-content/plugins/`.
2. Activate `WP Restaurant Menu` from the WordPress Plugins screen.
3. Make sure Elementor is installed and active.
4. Edit a page with Elementor and add the `Restaurant Menu` widget from the `WP Restaurant Menu` category.
